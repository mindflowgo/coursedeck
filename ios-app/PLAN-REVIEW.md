# Plan Review — Consolidated Findings

> **SUPERSEDED TOOLCHAIN NOTES:** this document records the original review rounds. The latest user scope (2026-10-24) keeps the current **Xcode 16.0 / iOS 18.0 SDK**, targets **iPadOS 18.0**, and removes PDF export and scheduling/calendar from v1. Any Xcode 26.3 / iOS 18.7 / PDF / schedule recommendations below are historical and must not be implemented. See `PLAN.md` for the authoritative plan.

Reviewed plan: [`PLAN.md`](./PLAN.md).
Review lenses: desktop-behavior correctness, iOS engineering feasibility, product/data safety.
Verdict: **the architecture is sound, but the plan is not executable as written.** Seven blockers and roughly fifteen high-severity issues must be resolved before coding. Many are data-loss or “feature silently doesn’t work” risks, not polish.

## 3. Medium / low findings

- **Backup hardening:** optional encryption, entry-count/size/compression-ratio limits, free-space check for zip + extraction (~2×), stage in Application Support/temp, delete archive after import.
- **Restore semantics:** define merge-by-default vs replace-all, automatic timestamped snapshot, course-scoped import, atomic commit.
- **Corrupt data:** quarantine `checkpoint.json`/`meta.json` on parse failure, keep `.bak`, refuse to save empty state over corrupt data.
- **Backup import of device-local files:** exclude `.jobs.json`, `.google_credentials.json`, `.arc_credentials.json`, `.mcp-token`, `.cleanup_queue.json`, `backend.log`, `lessonProgress/` (or preserve `lessonProgress` explicitly).
- **Legacy files:** `summary-2`/`sum2` and other orphan files are invisible to the desktop regex; preserve them on import/export and document whether they render.
- **Custom tab deletion:** two-step confirmation + trash/undo/snapshot.
- **Image UX:** long-press size menu that rewrites the pipe spec; block/confirm remote images.
- **PDF fidelity:** repeated table headers, row splitting, math fallback, images, answer key; measure memory/time.
- **LLM timeout mapping:** legacy `timeoutSeconds: 150` conflicts with the new connect/idle/total model; map and test a >150 s generation.
- **Deep links:** validate IDs/path containment; require confirmation for external-link auto-creation on cold launch.
- **Schedule preferences block:** port `stripStudentPreferencesBlock` so regeneration doesn’t duplicate it.
- **Settings contract:** define schema/defaults; desktop theme/resume live outside the data dir, so backup roundtrip won’t preserve them.
- **App versioning:** stamp version/build in About/backups; keep last known-good IPA; require export before upgrade; document downgrade data loss.
- **Privacy manifest/licenses:** add `PrivacyInfo.xcprivacy`, About/Licenses screen, SwiftMath font licenses (GUST/SIL), swift-markdown Apache 2.0 notice.
- **Diagnostics/perf:** add a real-library fixture (542 MB, 125 lessons, 547 Markdown, 188 MB assets) rather than synthetic-only tests.
- **Free-account slots:** iPadMonitor and itube occupy two of three free-app slots; the third is this app. Document the constraint.
- **iLoader bundle ID/team rewriting:** verify Keychain and data-container stability across re-signs; do not hardcode the signed bundle ID.

## 4. What the plan gets right

- Native SwiftUI/UIKit with a testable `CourseDeckCore`, no WebView/JS/server, is the correct architecture for the light-app goal.
- Path/tab validation, unit/course filename helpers, and reserved-tab rules closely match the desktop.
- The explicit out-of-scope list for MCP, SMTP/email, Ask-AI creation/deletion, and mhchem is sensible; read-only USERNOTE rendering preserves the data.
- The table defect list correctly identifies real desktop failures: surplus-cell truncation, `~~~`/indented-code corruption, image/math pipes, complete multiline headers, stacked-table separation, and the need for a 500-row performance test.
- The math currency edge cases match `isLikelyInlineMath`.
- The AI plan captures the important desktop behavior: one active card, URL resolution + 404 fallback, SSE, usage capture, retry classes, configurable timeouts, Keychain, no default `session_id`.
- Unit-test persistence and pop-quiz 300-second timing are correctly described.
- Practice/course tests are correctly treated as read-only.

## 5. Decisions required

1. **Toolchain:** install Xcode 26.3 (recommended, enables 18.7) after resizing the VM disk; or accept Xcode 16.0 + deployment target 18.0.
2. **Scope:** commit PDF to Phase 5 and Google Calendar/ARC to Phase 6, or explicitly descope them with sign-off. “All features” must not be claimed while they remain optional.
3. **Editing/selection:** accept the block reader + plain editor for v1, but add find-in-document, copy-section, task toggles, and table-cell editing; otherwise invest in a single TextKit 2 prose document and preview mode.
4. **Key/backup policy:** no plaintext key export; allowlisted, secret-scrubbed, optionally encrypted backups; merge-by-default with snapshots; re-enter keys after reinstall/team change.
5. **Device lifecycle:** treat 7-day re-signing as a weekly maintenance task with in-app reminder + mandatory export; test install-over; recommend a paid account if available.
6. **Prompt source:** bundle the reviewed active prompts plus `backup/test.md` and `backup/course_cheatsheet.md`; fail the build if a required prompt is missing; decide whether `test_kica.md` is required.
7. **AI cards/auth:** keep DeepSeek + GLM multi-card with active selector; normalize DeepSeek to Bearer, preserve custom headers for other hosts, test both cards.
8. **Privacy disclosure:** first-run consent naming DeepSeek/GLM and what is sent; redact logs; no analytics.
9. **Parity additions:** add course aggregate notes, unit assignments, search, checkpoint hub, rename/archive, archived-course preservation, and `dataVersion` to Phase 1/2.
