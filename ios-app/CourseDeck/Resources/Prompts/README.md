# Prompts (staged)

The Markdown prompt files in this folder are **generated by
`scripts/stage-prompts.ps1`** from the desktop prompt root
(`C:\Users\Meeoowz\Documents\ILC\_ILC-APP-DATA\prompts`) and are intentionally
gitignored. `build-ipa.ps1` runs the staging script before every sync, so a
fresh clone needs the desktop data folder to build.

Staging rules:

- Active prompts: `summary`, `cheatsheet`, `popquiz`, `unit_assignments`,
  `unit_test`, `course_summary`, `course_test`, `course_schedule`.
- Backup-only prompts: `test` and `course_cheatsheet`.
- Excluded: `mcp_prompt_instructions.md`, `promtps.zip`, `.DS_Store`,
  `.mcp-token`, and the `backup/` directory itself.
- `test.md` and `course_test.md` get reviewed schema overrides so the output
  schema matches the requested counts (6 MC + 4 FIB; 12 MC + 4 multi-part).
- `prompt-manifest.json` records required IDs, SHA-256 hashes, provenance, and
  expected question counts. The app does not ship without the full set.

`lesson` and `test_kica` are protected-if-present, but neither is required.
