## What does the word transformation mean?

In general, a transformation is a change in shape, appearance, size or position. In the grade 10 curriculum, we learn about transformations of quadratic functions. We are going to extend these concepts to more functions in this course.

### Where and how are transformations used in real life?

Transformations can be used to create computer generated art, pictures, commercials, and animated demonstrations containing special effects. Special effects are sometimes a result of changing the parameters in the algebraic representation of a parent function.

Now let’s discuss strategies of sketching the parent functions without technology

#### [Quadratic parent function: f x \= x 2](#accordion1-collapse1)

To sketch the quadratic parent function f x \= x 2 without technology, make a table of values by choosing your _x_\-values. When choosing _x_\-values, you need to make a wise choice by using both positive and negative numbers since the parabola is symmetric about the _y_\-axis. Consider using -2, -1, 0, 1, and 2. These five _x_\-values cover the most important parts of the graph. To calculate the corresponding _y_\-values, square each _x_\-value. Then plot the points and draw a smooth curve since you now know the general shape of the graph

**Note:**  
There is no restriction on your choice of _x_\-values because squaring any _x_\-value gives a valid _y_\-value.

Example

| x | f x |
| --- | --- |
| \-2 | f − 2 \= − 2 2 \= 4 |
| \-1 | f − 1 \= − 1 2 \= 1 |
| 0 | f 0 \= 0 2 \= 0 |
| 1 | f 1 \= 1 2 \= 1 |
| 2 | f 2 \= 2 2 \= 4 |

#### [Square root parent function: f x \= x](#accordion1-collapse3)

To sketch the square root parent function f x \= x without technology, make a table of values by choosing your _x_\-values. When choosing _x_\-values, you need to make a wise choice by using perfect squares ( 0 2 \= 0 , 1 2 \= 1 , 2 2 \= 4 , 3 2 \= 9 ) to avoid working with decimals. Consider using 0, 1, 4, and 9. These four _x_\-values cover the most important parts of the graph. To calculate the corresponding _y_\-values, take the positive square root of each _x_\-value. Then plot the points to draw a smooth curve starting at (0,0).

**Note:**  
There is a restriction on your choice of _x_\-values because you can only find the square root of zero and positive numbers, not negative numbers.

Example

| x | f x |
| --- | --- |
| 0 | f 0 \= 0 \= 0 |
| 1 | f 1 \= 1 \= 1 |
| 4 | f 4 \= 4 \= 2 |
| 9 | f 9 \= 9 \= 3 |

#### [Rational parent function: f x \= 1 x](#accordion1-collapse4)

To sketch the rational parent function f x \= 1 x without technology, make a table of values by choosing your _x_\-values. When choosing _x_\-values, you need to make a wise choice by using both positive and negative numbers since the rational function is symmetric about the origin. Consider using -2, -1, 0 (_x_ = 0 is the vertical asymptote), 1, and 2. These five _x_\-values cover the most important parts of the graph. To calculate the corresponding _y_\-values, find the reciprocal of each _x_\-value. Then plot the points to draw the two curves that approach the vertical asymptote _x_ = 0 and the horizontal asymptote _y_ = 0. One curve in the first quadrant and the other one in the third quadrant.

**Note:**  
The only restriction on your choice of _x_\-values is that _x_ cannot equal zero since dividing by zero is undefined.

Example

| x | f x |
| --- | --- |
| \-2 | f − 2 \= 1 − 2 \= − 0.5 |
| \-1 | f − 1 \= 1 − 1 \= − 1 |
| Vertical asymptote x \= 0 | Horizontal asymptote y \= 0 |
| 1 | f 1 \= 1 1 \= 1 |
| 2 | f 2 \= 1 2 \= 0.5 |

### Summary of Transformations

| Transformation | Name of Transformation | Effect on Graph | Effect on Points |
| --- | --- | --- | --- |
| f x + c | Vertical Translation | c > 0: Graph moves up c units
c < 0: Graph moves down c units

 | (x, y + c) |
| f x − d | Horizontal Translation | d > 0: Graph moves right d units

d < 0: Graph moves left d units

 | (x + d, y) |
| a f x | Vertical Stretch | a > 1: Graph is stretched vertically by a factor of a.

0 < a < 1: Graph is compressed vertically by a factor of a.

 | (x, ay) |
| f k x | Horizontal Stretch | k > 1: Graph is compress horizontally by a factor of 1 k

0 < k < 1: Graph is stretched horizontally by a factor of 1 k

 | x k , y |
| − f ( x ) | Vertical reflection | Graph is reflected across the _x_\-axis | (x, -y) |
| f ( − x ) | Horizontal reflection | Graph is reflected across the _y_\-axis | (-x, y) |

-   any transformation done **_inside_** the function (k and d) affects the _x_\-values in the **_opposite_** manner
-   any transformation done **_outside_** the function (a and c) affects the _y_\-values in a **_direct_** manner

### Summary

#### [Transformation statement: x , y → x k + d , a y + c](#accordion2-collapse1)

The transformation statement is a statement that summarizes the effects of the parameters a, k, d and c on the x and y coordinates. It can be used to determine the coordinates of a transformed point, given a point on the parent function, or vice versa.

To calculate the transformed x coordinate, divide the original _x_\-value by **_k_** since **_k_** is a horizontal stretch or compression by 1 k (multiplying by 1 k is the same as dividing by **_k_**) then add d to the answer since **_d_** is a horizontal shift left or right.

To calculate the transformed y coordinate, multiply the original _y_\-value by **_a_** since **_a_** is a vertical stretch or compression by **_a_** then add **_c_** to the answer since **_c_** is a vertical shift up or down.

#### [Order of Transformations:](#accordion2-collapse2)

When describing transformations, start with stretches, compressions and reflections in any order, then describe translations last.

### Domain and range of transformed functions

We can determine domain and range given an equation by using our knowledge of transformations

> [!NOTE]
> ### Recall
> -   any transformation done _inside_ the function affects the _x_\-values, therefore, k and d affect the domain
> -   any transformation done _outside_ the function affects the _y_\-values, therefore, a and c affect the range

  

#### Summary

| Parent Function | Transformed Function | Domain | Range |
| --- | --- | --- | --- |
| Linear
f x \= x

 | g x \= a k x − d + c | Not restricted

D \= x ∈ R

 | Not restricted

R \= y ∈ R

 |
| Quadratic

f x \= x 2

 | g x \= a k x − d 2 + c

 | Not restricted | 

a positive :

R \= y ∈ R  |  y ≥ c

a negative :

R \= y ∈ R  |  y ≤ c

 |
| square root

f ( x ) \= x

 | g x \= a k x − d + c | k positive :

D \= { x ∈ R  |  x ≥ d }

k negative :

D \= x ∈ R  |  x ≤ d

 | a positive :

R \= y ∈ R  |  y ≥ c

a negative :

R \= y ∈ R  |  y ≤ c

 |
| Rational

f x \= 1 x

 | g x \= a 1 k x − d + c

or

g x \= a k x − d + c

 | k positive or negative :

D \= x ∈ R  |  x ≠ d

 | a positive or negative :

R \= y ∈ R  |  y ≠ c

 |

Remember: A circle is not a function

Circle x 2 + y 2 \= r 2

D \= x ∈ R  |  − r ≤ x ≤ r

R \= y ∈ R  |  − r ≤ y ≤ r
