b) Factor f x \= x 2 \- 2 x \- 8 . What do you notice?

<details class="suggested-answer">
<summary>Suggested Answer</summary>

This is a simple trinomial.

Find two numbers whose product is -8 and the sum is -2.

Since the product is negative and the sum is negative, it means that the numbers have opposite signs and the bigger number takes the sign of the middle term.

Use systematic guessing

\-8 1 \= \-8           \- 8 + 1 \= \- 7

\-4 2 \= \-8           \- 4 + 2 \= \- 2

Therefore, the numbers are -4 and 2

f ( x )   \= ( x \- 4 ) ( x + 2 )

We noticed that f x \= x 2 \- 2 x \- 8 is equal to f ( x ) \= ( x \- 4 ) ( x + 2 ) . These are equations of one function in different forms.
</details>

c) Change f x \= x 2 \- 2 x \- 8 to vertex form by completing the square. What do you notice?

<details class="suggested-answer">
<summary>Suggested Answer</summary>

Factor out **a** from x 2 \- 2 x ( a = 1)

f x \= 1 ( x 2 \- 2 x ) \- 8

Complete the square

b\=−2 thus ( −2 2 ) 2 \=1

Add and subtract 1 inside the bracket

f x \= 1 ( x 2 \- 2 x + 1 \- 1 ) \- 8

Then move -1 outside the bracket and multiply it by a (a = 1) to create a perfect square inside the bracket

f x \= 1 ( x 2 \- 2 x + 1 ) \- 1 ( 1 ) \- 8

f x \=1 x 2 −2x+1 −9

Factor the perfect square trinomial inside the bracket and simplify the terms outside the bracket

x 2 \= x 1 \= 1 and the sign of the middle term is -, so

x 2 \- 2 x + 1 \= x \- 1 2

Thus,

f x \= x \- 1 2   \- 9

We noticed that f x \= x 2 \- 2 x \- 8 is equal to   f x \= x \- 1 2   \- 9 .

These are equations of the same function in different forms.
</details>

**Conclusion:**

Is it enough to compare given functions by just examining the given equations?

<details class="suggested-answer">
<summary>Suggested Answer</summary>

-   It is not enough to compare given functions by just looking at the given equations because the equations might just be different forms of the same function.
-   f x \= x 2 \- 2 x \- 8 , f ( x ) \= ( x \- 4 ) ( x + 2 ) and f x \= x \- 1 2   \- 9 are equivalent functions because they produce the same graph. If you expand and simplify f ( x ) \= ( x \- 4 ) ( x + 2 ) and f x \= x \- 1 2   \- 9 they both become f x \= x 2 \- 2 x \- 8 .
</details>

### Rational functions

Now let's extend the concept of equivalence to rational functions.

#### Restrictions of the variable

**A rational function** is any function that is in the form of a fraction where both the numerator and the denominator are polynomials and the denominator cannot be equal to zero, since division by zero is impossible.

Since division by zero is impossible, each rational function has to be restricted by stating the values of the variables that make the function undefined. These are the zeros of the denominator and they are called restrictions.

**Note:**

If the function has a divisor and a dividend that are both fractions, you have to take restrictions for both numerator and denominator for the divisor, since the divisor cannot be zero.

A **divisor** is a function or number by which another function or number is to be divided.

The function being divided is called the **dividend**.

**Example:** x \- 7 x + 2   ÷ x 2 + 5 x + 6 x + 2

x \- 7 x + 2 is the dividend and x 2 + 5 x + 6 x + 2 is the divisor.

To determine the restrictions on the variable, use the factored form of the given function.

#### Writing equivalent rational expressions

Recall: given two or more rational functions or expressions, you can conclude that they are equivalent if:

-   they simplify algebraically to give the same function or expression
-   the corresponding y-values for at least three chosen x-values are equal (at least 3 numbers are used to make sure that some of the points used are not just points of intersection of the graphs of the functions)
-   the two functions produce the same graph

By simplifying a given function, you are creating a function that is equivalent to the given function (both equations produce the same graph).

There are a number of strategies that can be used to simplify rational functions depending on the form of the rational function.

Since rational functions are fractions, we will apply our knowledge of simplifying fractions to simplify rational functions in different forms.

**Note:**

You can only reduce or simplify a rational expression if there is a common factor in both the numerator and the denominator. Common factors will divide out to make the expression simpler. Therefore, start by factoring the numerator and denominator to simplify expressions where possible, otherwise just group like terms and simplify. The method described above is applicable to any rational function.
